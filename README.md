# ZonaCaninaVaporcito — El Puerto de Santa María 🐾

**Campaña ciudadana por una zona canina en Avenida Bajamar 44 (donde estaba el Vaporcito) y una red equitativa por barrios.**

Tu perro merece más que una acera. El Puerto tiene ~9.000 hogares con perro y solo 2–3 zonas caninas dignas. La Ley 7/2023 obliga a los municipios a habilitar espacios de esparcimiento canino. Ya lo conseguimos con la playa de El Aculadero (2024) — ahora toca el Vaporcito.

> **Firma la petición (30 segundos, gratis):** https://c.org/TBtrVxzFjv — alternativa https://c.org/djqGV9J6Ct
